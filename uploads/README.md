# Text Summarization Tool

This is a simple web-based text summarization project built using Python, Flask, and NLTK.

## Features
- Summarizes long text into short form
- Web-based interface
- Uses NLP techniques

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000
